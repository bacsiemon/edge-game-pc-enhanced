## Layout & Consistency

- **Submenu Navigation & `>` Indicators:** All rows opening nested submenus display a right-aligned `>` arrow (`Main Menu` rows `edge challenge`, `scores`, `options`; `edge challenge` rows `normal`, `extended levels`, `bonus levels`; `scores` rows `normal`, `extended`, `bonus`; Pause root row `options` at index `3`; Options root rows `display`, `graphics`, `audio`, `ui`, `gameplay`; `Graphics` conditional row `customize theme` when `theme == custom`; `UI` rows `timer`, `prism counter`, `minimap`, `speedometer`). `instructions` sits on `Main Menu` below `options` (removed from `edge challenge`).
- **Uniform Row Sizing, Widened Menus & Scrollable Lists:** Widens menus to `368px` (`0x170`) with Pause root slots (`0x26` stride) matched to Pause Options, and shifts row text slightly up so under-value dots and slider bars fit cleanly above dividers. `ComputeMainOptLayout` and `ComputePauseOptRowH` dynamically compact row height when a category has many rows so rows never clip even at small virtual heights (`virtH = 512`), while `Graphics -> Customize Theme` uses a D3D9 scissored scrollable viewport (`ScopedUiScissor` + `WM_MOUSEWHEEL`, draggable scrollbar, and keyboard auto-scroll) with a pinned `back` row at the bottom.
- **Sample & Live HUD / Minimap / Graphics Previews:** Corner HUD Timer, Prism Counter, & Speedometer render during gameplay and stay hidden while paused—except when inside **UI -> Timer**, **UI -> Prism Counter**, or **UI -> Speedometer** (in either Main Options or Pause Options), where they render a sample (Main Options, or Pause Options when unbuffed on Speedometer) or live (Pause Options) preview. Inside **UI -> Minimap**, the customized minimap renders a live (Pause Options) or animated sample (Main Options) preview docked beside the menu strip (or dimmed in its target corner when focusing/opening `position`, alongside any enabled Timer / Prism Counter / Speedometer). When adjusting `type`/`enable`, `size`, `background`, or `drop shadow` on Timer / Prism Counter / Speedometer, the preview always renders at full opacity and docks to the right of the menu strip so it never overlaps menu text (even if Timer/Prism `type` is currently `off`, or while adjusting Speedometer `size`/`background`/`drop shadow`/`position`); when focusing or opening `position`, it dims and snaps to the actual target corner (alongside companion overlays if enabled). During Pause, the Pause menu header directly embeds the full 2-row timer + progress bar above the prism strip. In Main Menu **Options -> Graphics** (and **Customize Theme**), the EDGE logo background is swapped for a live `WorldScreen` rendering the loose `levels/graphics_preview.bin` showcase island framed to the right of the menu strip (`light 1`/`light 2`/`dark 1`/`dark 2`), featuring a hint ghost positioned northwest of the `?` hint tile, with live hover-preview on `preview level`, `edge timer`, `theme`, and `customize theme` popups, fast-forwarded `cube idle distortion` only while hovering `cube idle distortion`, animated `edge timer` while hovering `edge timer`, live `prism vfx` screen trigger on value change, and `cube shatter` & `finish effect` animation triggers on value change or popup hover.

## Control Behavior Guidelines

### 1. Toggles (15 items)

- **Display:** 2 dots under the value. Lighter dot indicates the selected option.
- **Interaction:** Click / Enter / Left / Right toggles immediately and saves, playing hover SFX (`2`).

### 2. Popups (28 setting popups + 1 confirm popup)

- **Display:**
  - Setting popups show multiple horizontal dots under the value (lighter dot indicates the selected option). Action confirm popups (`reset score`) show no dots under the row.
  - Popup anchors **below** the option row by default to preserve visual flow, flipping **above** the row if there is insufficient vertical space below.
  - Shows all valid choices, marking the active choice and **highlighting the default value with a dot** (or `no` / `yes` with `no` focused by default for `reset score`).
- **Interaction:**
  - **Click / Enter** on the row opens the anchored popup, playing hover SFX (`2`).
  - **Up / Down / Mouse Hover + Enter / Click** picks a choice (or confirms/cancels for `reset score`), closes the popup, and saves: setting choices play select SFX (`0xc`), choosing `no` plays back SFX (`0xb`), and confirming `reset score` (`yes`) plays level start / final confirm SFX (`0x1`). Moving the mouse off-popup in mouse mode clears the choice highlight; pressing Up/Down/Enter restores the last highlighted choice first; hovered choices use subtle (`25%`) rainbow with a 2px rainbow border and switch to strong rainbow while pressed.
  - **Esc / Cancel / Click outside** closes without changing the value / without resetting, playing back SFX (`0xb`).
  - **Left / Right** on the row (when popup is closed) quick-cycles setting popups as a shortcut (disabled on `reset score`), playing hover SFX (`2`).

### 3. Sliders (17 items)

- **Display:**
  - A bar under the value. Lighter portion indicates progress.
  - A **dot/tick marker** on the track highlights the default value.
- **Interaction:**
  - **Mouse:** Click anywhere on the track to jump, drag thumb to scrub (pointer stays captured and row stays strong rainbow even if cursor leaves the row vertically), and release to save. Value changes during scrubbing play hover SFX (`2`).
  - **Keyboard / Gamepad:** Left / Right steps by preset or fixed increment (`5` for `sounds`/`music`, `10` for `background`/`drop shadow`, preset index for `prism vfx`/`ui scale`/`size`/`width`/`height`/`range`), playing hover SFX (`2`).
  - **Reset to default:** Press `R` / `Backspace` / `Delete` while a slider row is focused to snap back to the default value, playing hover SFX (`2`).
  - **Special case (`ui scale`):** Update the displayed slider value while dragging/stepping, and call `ApplyUiScale` + `SaveModSettings` on mouse-up / Left-Right release (or cursor/focus change) without reverting `auto scale` to `off` (all mod options save atomically to `%LocalAppData%\Two Tribes\EDGE\edgemod_settings.ini`; vanilla options `fullscreen`, `sounds`, `music`, `up key`, and `reset score` continue using `Game_SaveUserSettings`).
  - **Special case (`minimap` `enable` / `width` / `height` / `range` / `position`):** Read-only against `%LocalAppData%\Two Tribes\EDGE\settings.ini`: until adjusted in the menu (`minimap_*_override = 0`), the game uses `settings.ini` values directly; once changed in Options (`minimap_*_override = 1`), the chosen option takes effect (with `width`/`height`/`range` scaling the `160px` / `19.5` baseline), unless `settings.ini` is later edited on disk.
